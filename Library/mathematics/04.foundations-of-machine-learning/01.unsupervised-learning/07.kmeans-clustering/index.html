The Big Picture: Discovering Structure Without Labels

In the previous lessons on PCA, we looked for a continuous flat subspace that captures the most information while removing redundancy. We compressed high-dimensional data by projecting it along a few continuous orthogonal sliders.

Now consider a different question: what if our data doesn't vary smoothly along a single continuous plane, but instead falls into distinct types?

Instead of continuous sliders, we want discrete anchors—a small set of prototypes or centroids that summarize the space. We want to know: what kinds of data points do we have, and how do they sit with each other?

Why do we benefit from grouping data like this? Think about a collection of images of cats and dogs. A single high-resolution image might contain a million pixels. It is impossible to reason about a million raw numbers directly. But if an algorithm groups the images into clusters, simply knowing that an image belongs to the "Cat" cluster immediately tells you what that data point is like—it likely has whiskers, pointed ears, and fur. You trade away individual pixel quirks in exchange for immediate semantic predictability.

In information theory and signal processing, this idea is called Vector Quantization: instead of storing continuous coordinates for every point, we summarize the entire dataset using a compact "codebook" of $K$ representative prototypes, known as cluster centroids ($\mu_1, \dots, \mu_K \in \mathbb{R}^d$). Every observation is then approximated by its nearest centroid.

This formulation exposes a fundamental mutual dependency (a classic chicken-and-egg dilemma):

  • If we knew the centroid locations: assigning each observation would be trivial—simply map each point to whichever centroid is geometrically closest.
  • If we knew the cluster assignments: calculating the optimal centroids would be trivial—simply compute the arithmetic average (center of mass) of each cluster's assigned points.

Because neither set of variables can be determined without already knowing the other, we cannot solve for both in closed form simultaneously. The point assignments depend entirely on knowing where the centroids are located, while each centroid's position depends entirely on knowing which points belong to its cluster.

If we seek the best discrete partition of data, what mathematical objective captures our clustering error, and how do we optimize both cluster assignments and centroids simultaneously?

The Distortion Objective & Lloyd's Alternating Descent

Suppose we are given $n$ observations $x_1, x_2, \dots, x_n \in \mathbb{R}^d$. Our goal is to partition this dataset into $K$ disjoint groups $C_1, C_2, \dots, C_K$ such that $\bigcup_{k=1}^K C_k = \{1, 2, \dots, n\}$, with each group represented by an idealized central prototype $\mu_k \in \mathbb{R}^d$.

Let $z_i \in \{1, 2, \dots, K\}$ denote the discrete assignment label for observation $x_i$, indicating that point $x_i$ belongs to cluster $C_{z_i}$. How do we evaluate whether a given choice of assignments $\{z_i\}$ and centroids $\{\mu_k\}$ is good? A natural geometric criterion is the total squared Euclidean distance between every data point and its assigned cluster prototype. This objective is known as the distortion objective or cluster inertia:

$$\begin{aligned} F(z_1, \dots, z_n, \mu_1, \dots, \mu_K) &= \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2 \\[8pt] &= \sum_{k=1}^K \sum_{i \in C_k} \|x_i - \mu_k\|^2 \end{aligned}$$

This optimization problem presents a formidable mathematical bottleneck. It simultaneously couples discrete combinatorial variables ($z_i \in \{1, \dots, K\}$) with continuous geometric vectors ($\mu_k \in \mathbb{R}^d$).

Consider the sheer scale of the assignment space: each of the $n$ data points can independently choose any of the $K$ clusters, giving a total of $K^n$ possible assignments:

  • Even for a toy problem with just $n = 5$ points and $K = 3$ clusters, there are $3^5 = 243$ possible assignments.
  • For a small dataset of $n = 50$ points and $K = 4$ clusters, $4^{50} \approx 1.27 \times 10^{30}$ assignments—vastly exceeding the number of seconds since the Big Bang.

In fact, globally finding $\min_{\{z_1, \dots, z_n\}} \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2$ is proven to be NP-hard even for $K = 2$ in general dimensions, or for $d = 2$ with arbitrary $K$. We cannot exhaustively check all partitions.

Faced with this combinatorial barrier, Stuart Lloyd (1957) proposed an elegant coordinate descent strategy. While optimizing $z$ and $\mu$ simultaneously is intractable, optimizing either set of variables while holding the other set fixed is remarkably straightforward:

Subproblem 1: Optimizing Centroids for Fixed Assignments

Suppose the cluster memberships $z_1, \dots, z_n$ are held constant. The overall objective decomposes into $K$ independent sub-problems, one for each cluster $k$:

$$\mu_k^* = \arg\min_{\mu \in \mathbb{R}^d} \sum_{i \in C_k} \|x_i - \mu\|^2$$

Because each sub-problem is a smooth, unconstrained convex quadratic function of $\mu$, we find the global minimizer by computing the gradient and setting it to zero:

$$\begin{aligned} \nabla_\mu \left[ \sum_{i \in C_k} (x_i - \mu)^T (x_i - \mu) \right] &= \sum_{i \in C_k} \left( -2(x_i - \mu) \right) \\[8pt] &= -2 \sum_{i \in C_k} x_i + 2 |C_k| \mu = \mathbf{0} \end{aligned}$$

Solving directly for $\mu$ yields the sample arithmetic mean:

$$\mu_k^* = \frac{1}{|C_k|} \sum_{i \in C_k} x_i = \frac{\sum_{i=1}^n x_i \mathbf{1}(z_i = k)}{\sum_{i=1}^n \mathbf{1}(z_i = k)}$$

Under squared Euclidean distance, the unique optimal representative of a point set is its center of mass (arithmetic mean). This explains why the algorithm is named $K$-Means.

Subproblem 2: Optimizing Assignments for Fixed Centroids

Now suppose the centroids $\mu_1, \dots, \mu_K$ are held constant. The objective $F(z, \mu) = \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2$ splits into $n$ completely independent terms—one for each data point $x_i$. To minimize the total sum, we simply assign each point to its nearest centroid:

$$z_i^* = \arg\min_{k \in \{1, \dots, K\}} \|x_i - \mu_k\|^2$$
Lloyd's Alternating Algorithm
  1. Initialization: Choose $K$ initial centroid vectors $\mu_1^{(0)}, \mu_2^{(0)}, \dots, \mu_K^{(0)} \in \mathbb{R}^d$ (or initial cluster indicators $z_1^{(0)}, \dots, z_n^{(0)} \in \{1, \dots, K\}$).
  2. Mean Calculation Step: For each cluster $k \in \{1, \dots, K\}$, compute its center of mass: $$\mu_k^{(t)} = \frac{\sum_{i=1}^n x_i \mathbf{1}(z_i^{(t)} = k)}{\sum_{i=1}^n \mathbf{1}(z_i^{(t)} = k)}$$
  3. Reassignment Step: Assign each point to its closest centroid: $$z_i^{(t+1)} = \arg\min_{k \in \{1, \dots, K\}} \|x_i - \mu_k^{(t)}\|^2$$ Rule: Reassignment happens only if a strictly better (strictly closer) cluster center is found. If a point is equidistant to its current center, it stays put.
  4. Convergence Check: Repeat steps 2 and 3 until no assignments change ($z^{(t+1)} = z^{(t)}$), meaning every point is assigned to its optimal centroid.

Concrete Grounding: A Hands-On 2D Numerical Walkthrough

Before diving into higher-dimensional geometry, let us ground Lloyd's alternating steps in a tangible two-dimensional dataset with real numbers. Seeing the arithmetic in action reveals how coordinate descent drives down the distortion objective step by step.

Consider four observations in $\mathbb{R}^2$:

$$x_1 = \begin{bmatrix} 1 \\ 2 \end{bmatrix}, \quad x_2 = \begin{bmatrix} 2 \\ 1 \end{bmatrix}, \quad x_3 = \begin{bmatrix} 6 \\ 8 \end{bmatrix}, \quad x_4 = \begin{bmatrix} 7 \\ 9 \end{bmatrix}$$

We set $K = 2$ and choose two arbitrary starting vectors in $\mathbb{R}^2$:

$$\mu_1^{(0)} = \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \quad \mu_2^{(0)} = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$$

A note on initialization: In practical implementations and algorithms like $k$-means++, initial centroids are usually chosen by sampling actual data points from the dataset (known as Forgy initialization, discussed in Section 6). Here, we deliberately select two arbitrary points not in the dataset to demonstrate an important property: because the parameter space $\mu \in \mathbb{R}^d$ is continuous, Lloyd's algorithm works from any initial coordinates in space—the first centroid update step will automatically pull them onto the exact centers of mass of the data.

Iteration 1 — Assignment Step

We evaluate the squared Euclidean distances $\|x_i - \mu_k^{(0)}\|^2$ from each point to both centroids:

Point $\|x_i - \mu_1^{(0)}\|^2$ $\|x_i - \mu_2^{(0)}\|^2$ Assignment
$x_1 = (1, 2)$ $1$ $2$ $z_1^{(1)} = 1$
$x_2 = (2, 1)$ $1$ $4$ $z_2^{(1)} = 1$
$x_3 = (6, 8)$ $74$ $41$ $z_3^{(1)} = 2$
$x_4 = (7, 9)$ $100$ $61$ $z_4^{(1)} = 2$

Total initial distortion: $F(z^{(1)}, \mu^{(0)}) = 1 + 1 + 41 + 61 = 104$.

Iteration 1 — Centroid Update Step

Recomputing centroids as the arithmetic means of their assigned points:

$$\mu_1^{(1)} = \frac{x_1 + x_2}{2} = \begin{bmatrix} 1.5 \\ 1.5 \end{bmatrix}, \quad \mu_2^{(1)} = \frac{x_3 + x_4}{2} = \begin{bmatrix} 6.5 \\ 8.5 \end{bmatrix}$$

Each point is now at squared distance $\|x_i - \mu_{z_i}^{(1)}\|^2 = 0.5$ from its new centroid, collapsing total distortion:

$$F(z^{(1)}, \mu^{(1)}) = 4 \times 0.5 = 2.0$$

The distortion collapsed from $104 \to 2.0$ in a single iteration. Checking Iteration 2 confirms that no assignments change ($z^{(2)} = z^{(1)}$), and the algorithm terminates.

What geometric boundaries carve up space between competing centroids, and why are $K$-means clusters fundamentally constrained to be convex polygons?

The Geometry of Clusters: Why Boundaries are Hyperplanes

To uncover the geometric shapes carved out by $K$-means, let us analyze the decision boundary separating any two cluster centers $\mu_1$ and $\mu_2$.

A point $x \in \mathbb{R}^d$ is assigned to Cluster 1 rather than Cluster 2 if and only if it is closer to $\mu_1$ than to $\mu_2$ in squared Euclidean distance:

$$\|x - \mu_1\|^2 \le \|x - \mu_2\|^2$$

Expanding both norms using inner products reveals an essential algebraic cancellation:

$$\begin{aligned} \underbrace{\|x\|^2 - 2x^T \mu_1 + \|\mu_1\|^2}_{\|x - \mu_1\|^2} &\le \underbrace{\|x\|^2 - 2x^T \mu_2 + \|\mu_2\|^2}_{\|x - \mu_2\|^2} \\[8pt] -2x^T \mu_1 + \|\mu_1\|^2 &\le -2x^T \mu_2 + \|\mu_2\|^2 \\[8pt] 2x^T (\mu_2 - \mu_1) &\le \|\mu_2\|^2 - \|\mu_1\|^2 \\[8pt] x^T (\mu_2 - \mu_1) &\le \frac{\|\mu_2\|^2 - \|\mu_1\|^2}{2} \end{aligned}$$

The quadratic term $\|x\|^2$ appears on both sides with identical sign and magnitude, canceling out completely. What remains is purely linear in $x$:

The Separating Hyperplane Equation
$$x^T (\mu_2 - \mu_1) \le \frac{\|\mu_2\|^2 - \|\mu_1\|^2}{2}$$

The decision boundary is the equality surface $x^T w = b$, where the normal vector is $w = \mu_2 - \mu_1$ and the scalar offset is $b = \frac{\|\mu_2\|^2 - \|\mu_1\|^2}{2}$.

To verify where this boundary sits in space, evaluate what happens at the geometric midpoint $m = \frac{\mu_1 + \mu_2}{2}$:

$$\begin{aligned} m^T (\mu_2 - \mu_1) &= \left(\frac{\mu_1 + \mu_2}{2}\right)^T (\mu_2 - \mu_1) \\[8pt] &= \frac{\mu_2^T \mu_2 - \mu_1^T \mu_1}{2} = \frac{\|\mu_2\|^2 - \|\mu_1\|^2}{2} \end{aligned}$$

The midpoint satisfies the equality condition exactly! Thus, the boundary is the perpendicular bisector of the line segment joining $\mu_1$ and $\mu_2$. It cuts orthogonally across the vector $\mu_2 - \mu_1$ at the exact halfway point.

This gives the exact algebraic and geometric role of the inner product: because $x$ is a position vector emanating from the origin, evaluating the dot product $x^T(\mu_2 - \mu_1)$ computes the orthogonal projection of vector $x$ along the normal direction $w = \mu_2 - \mu_1$. The scalar threshold $b = m^T(\mu_2 - \mu_1)$ represents the projection of the midpoint vector $m$ along that same normal axis. For any observation $x$ closer to $\mu_1$, its projection along $w$ from the origin is strictly less than the midpoint threshold ($x^T w < m^T w = b$), placing it on $\mu_1$'s side of the perpendicular bisector:

Generalization to $K > 2$: Voronoi Tessellations

When we move beyond two clusters to $K \ge 3$, each observation $x$ must be closer to its assigned centroid $\mu_k$ than to every other centroid simultaneously. Consequently, the region belonging to cluster $k$ is formed by the intersection of $K - 1$ linear half-spaces:

$$C_k = \bigcap_{j \neq k} \left\{ x \in \mathbb{R}^d : x^T(\mu_j - \mu_k) \le \frac{\|\mu_j\|^2 - \|\mu_k\|^2}{2} \right\}$$

When $K = 3$, the boundary between any pair of centroids $\mu_i$ and $\mu_j$ is simply the perpendicular bisector passing through their midpoint $m_{ij} = \frac{\mu_i + \mu_j}{2}$.

In classical Euclidean geometry, the perpendicular bisectors of the three sides of triangle $\triangle \mu_1 \mu_2 \mu_3$ are concurrent—they all intersect at a single point known as the circumcenter. In clustering and computational geometry, this three-way junction is called a Voronoi vertex ($V$).

At the Voronoi vertex $V$, a data point is equidistant from all three cluster centers:

$$\|V - \mu_1\| = \|V - \mu_2\| = \|V - \mu_3\|$$

The cluster boundaries separating the Voronoi cells are not infinite lines; rather, they are three rays emanating outward from $V$, each passing directly through the corresponding midpoint ($m_{12}, m_{13}, m_{23}$) and heading away from the third competing centroid. These three rays partition the continuous plane into three convex polygonal regions:

Because every individual half-space is a convex set, and the intersection of any collection of convex sets is guaranteed to be convex, every $K$-means cluster cell is fundamentally a convex polyhedron. This geometric partitioning of space into nearest-neighbor convex polygons is known as a Voronoi Tessellation.

This geometric reality exposes the primary limitation of $K$-means: it can never separate clusters whose natural boundaries are non-convex or non-linear (such as concentric circles, interlocking spirals, or moon shapes). In such geometries, the flat Voronoi hyperplanes unavoidably slice directly through natural clusters.

Can Lloyd's alternating descent get caught in an infinite cycle, oscillating between two partitions forever without stopping?

Why Lloyd's Algorithm Must Converge

Before deploying any iterative algorithm, four fundamental questions must be answered:

  1. Convergence: Is the algorithm guaranteed to terminate, or can it loop indefinitely?
  2. Initialization: How sensitive is the final partition to the starting seeds?
  3. Choice of $K$: How do we determine the true number of clusters in unlabeled data?
  4. Nature of Clusters: What geometric geometries can the algorithm successfully recover?

We address the first question here: Can Lloyd's algorithm get caught in an infinite cycle, endlessly bouncing points between clusters without ever halting?

The answer is no. Lloyd's algorithm is mathematically guaranteed to terminate in a finite number of steps. The proof proceeds in two elegant steps.

Step 1: The Reassignment Strict Inequality

Assume the algorithm has not yet converged at iteration $t$. This means at least one data point $x_i$ will change its cluster assignment at round $t+1$.

Recall the fundamental reassignment rule:

$$z_i^{(t+1)} = \arg\min_{k \in \{1, \dots, K\}} \|x_i - \mu_k^{(t)}\|^2$$

A point changes cluster membership if and only if a strictly closer centroid is found. For every point that moves, $\|x_i - \mu_{z_i^{(t+1)}}^{(t)}\|^2 < \|x_i - \mu_{z_i^{(t)}}^{(t)}\|^2$. For points that stay put, their distance remains identical.

Summing across all $n$ observations yields a strict inequality:

$$\sum_{i=1}^n \|x_i - \mu_{z_i^{(t)}}^{(t)}\|^2 > \sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t)}\|^2$$

Look closely at both sides of this strict inequality:

  • Left Side $\left(\sum_{i=1}^n \|x_i - \mu_{z_i^{(t)}}^{(t)}\|^2\right)$: The total distance from every point to its current mean (its current cluster box).
  • Right Side $\left(\sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t)}\|^2\right)$: The total distance from every point to the mean of the cluster where it wants to be (its next cluster box).

If this strict inequality does not hold, no point desires to move—every point is satisfied with its current center, and the algorithm has already converged.

Fact 1: Optimality of the Sample Mean

To analyze what happens when centroids update, we establish a foundational mathematical fact:

Fact 1: The Sample Mean Minimizes Squared Euclidean Distances

Let $\{x_1, \dots, x_\ell\} \subset \mathbb{R}^d$ be an arbitrary set of $\ell$ points. The vector $v^* \in \mathbb{R}^d$ that minimizes the sum of squared Euclidean distances to these points:

$$v^* = \arg\min_{v \in \mathbb{R}^d} \sum_{i=1}^\ell \|x_i - v\|^2$$

is uniquely the arithmetic sample mean:

$$v^* = \frac{1}{\ell}\sum_{i=1}^\ell x_i$$

The proof is immediate from calculus: expanding $\|x_i - v\|^2 = (x_i - v)^T (x_i - v)$ and setting the gradient with respect to $v$ to zero:

$$\begin{aligned} \nabla_v \left[ \sum_{i=1}^\ell \|x_i - v\|^2 \right] &= -2 \sum_{i=1}^\ell (x_i - v) = \mathbf{0} \\[8pt] \sum_{i=1}^\ell v &= \sum_{i=1}^\ell x_i \quad\Longrightarrow\quad \ell v = \sum_{i=1}^\ell x_i \quad\Longrightarrow\quad v^* = \frac{1}{\ell}\sum_{i=1}^\ell x_i \end{aligned}$$

Step 2: The Centroid Update Inequality

Now consider the second half of iteration $t+1$: recomputing the centroids.

For any cluster $k$, collect all points that chose cluster $k$ during the reassignment step:

$$\{i : z_i^{(t+1)} = k\}$$

The old centroid $\mu_k^{(t)}$ was fixed from the previous round. But the new centroid $\mu_k^{(t+1)}$ is computed as the exact arithmetic mean of these points:

$$\mu_k^{(t+1)} = \frac{\sum_{i=1}^n x_i \mathbf{1}(z_i^{(t+1)} = k)}{\sum_{i=1}^n \mathbf{1}(z_i^{(t+1)} = k)}$$

By Fact 1, the sample mean $\mu_k^{(t+1)}$ achieves the absolute lowest possible sum of squared distances for this point set over any vector in $\mathbb{R}^d$—including the old center $\mu_k^{(t)}$. Therefore, for every cluster $k$:

$$\sum_{i : z_i^{(t+1)} = k} \|x_i - \mu_k^{(t)}\|^2 \;\ge\; \sum_{i : z_i^{(t+1)} = k} \|x_i - \mu_k^{(t+1)}\|^2$$

Summing this inequality over all $K$ clusters ($k = 1, \dots, K$):

$$\sum_{k=1}^K \sum_{i : z_i^{(t+1)} = k} \|x_i - \mu_k^{(t)}\|^2 \;\ge\; \sum_{k=1}^K \sum_{i : z_i^{(t+1)} = k} \|x_i - \mu_k^{(t+1)}\|^2$$

Notice that every point $x_i$ belongs to exactly one cluster under $z^{(t+1)}$. The double summation collapses into a single sum over all $n$ data points:

$$\sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t)}\|^2 \;\ge\; \sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t+1)}\|^2$$

In plain terms:

Distance to the mean of the cluster where each point wants to be $\;\ge\;$ Distance to their own newly updated mean after reassignment.

Chaining the Two Inequalities: Strict Objective Descent

Now let us link Step 1 and Step 2 together:

$$\begin{aligned} \underbrace{\sum_{i=1}^n \|x_i - \mu_{z_i^{(t)}}^{(t)}\|^2}_{\text{Distance to current mean}} &>\; \underbrace{\sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t)}\|^2}_{\text{Distance to mean where points want to be}} \\[10pt] &\ge\; \underbrace{\sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t+1)}\|^2}_{\text{Distance to updated mean after reassignment}} \end{aligned}$$

Because the first link is a strict inequality ($>$) and the second link is non-increasing ($\ge$), the overall transition across one complete iteration is strictly decreasing:

$$\sum_{i=1}^n \|x_i - \mu_{z_i^{(t)}}^{(t)}\|^2 \;>\; \sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t+1)}\|^2$$

The performance metric (distortion objective) strictly reduces whenever any reassignment happens!

The Finite Partition Deduction

Why does strict objective reduction guarantee that Lloyd's algorithm must terminate?

  1. Partitions Cannot Repeat: Suppose the algorithm reached a partition $z^{(a)}$ at iteration $a$, and later visited the same partition $z^{(b)} = z^{(a)}$ at iteration $b > a$. Because the objective strictly decreases at every step with reassignment, the distortion at step $b$ would have to be strictly less than at step $a$: $$F(z^{(b)}, \mu^{(b)}) < F(z^{(a)}, \mu^{(a)})$$ However, identical assignments produce identical centroids $\mu^{(b)} = \mu^{(a)}$, requiring $F(z^{(b)}, \mu^{(b)}) = F(z^{(a)}, \mu^{(a)})$. This creates a direct contradiction! Therefore, no partition $z \in \{1, \dots, K\}^n$ can ever be visited twice.
  2. Finite Partition Space: Each of the $n$ points can be assigned to one of $K$ clusters. The total number of conceivable partitions is finite (at most $K^n$).
  3. Inevitable Termination: Since there are only finitely many partitions and the algorithm never revisits an earlier partition, the sequence of distinct partitions must eventually run out of states $\implies$ Lloyd's algorithm MUST converge in a finite number of steps!
Theorem: Finite Convergence of Lloyd's Algorithm

Because the distortion objective $F(z, \mu)$ strictly decreases whenever assignments change, partitions cannot repeat. Since the number of distinct partitions is finite ($K^n$), the algorithm cannot cycle indefinitely and must terminate after a finite number of iterations $\implies$ Convergence is mathematically guaranteed.

The Critical Caveat: We Say Nothing About Solution Quality!

Notice what this mathematical proof does not say: it guarantees that the algorithm will stop, but says absolutely nothing about the quality or global optimality of the converged solution.

Because the distortion landscape is heavily non-convex with numerous local valleys, Lloyd's algorithm readily converges to suboptimal local minima—where Voronoi boundaries split dense clusters in half.

If Lloyd's algorithm is a prisoner of its initial seeds, how can we initialize centroids so we are mathematically protected against catastrophic local traps?

Initialization Pitfalls & $k$-Means++ Careful Seeding

Historically, practitioners selected initial centroids $\mu_1^{(0)}, \dots, \mu_K^{(0)}$ using simple heuristic strategies:

  • Random Partition: Assign each point randomly to one of $\{1, \dots, K\}$ and compute initial cluster means. Because each random subset has approximately the same overall distribution, the Law of Large Numbers pulls all initial means close to the global dataset center $\bar{x}$, collapsing initial cluster separation.
  • Forgy Uniform Selection: Pick $K$ distinct observations uniformly at random from $\mathcal{X}$. While better than random partition, it frequently samples multiple seeds from dense clusters while leaving smaller, distinct clusters entirely unrepresented.

The Greedy Trap: Furthest-Point Initialization

To ensure that centroids spread across the data, one might naturally propose a deterministic greedy rule (furthest-first traversal): pick $\mu_1$ randomly from $\mathcal{X}$, and subsequently select each next center $\mu_\ell$ as the data point farthest from all existing centers:

$$\mu_\ell = \arg\max_{x_i \in \mathcal{X}} \min_{j \in \{1, \dots, \ell-1\}} \|x_i - \mu_j\|^2$$

While intuitive, this deterministic rule has a fatal flaw: it is hypersensitive to outliers. If the dataset contains even a single noise point or outlier far away from the true clusters, the greedy rule aggressively targets it as a legitimate centroid. Furthermore, on symmetric datasets (such as clusters arranged in parallel pairs or concentric rings), the furthest-point heuristic deterministically places seeds at opposite extremes of the same cluster, locking Lloyd's algorithm into pathological configurations with arbitrarily terrible approximation ratios compared to the true optimum.

The Breakthrough: $k$-Means++

In 2007, David Arthur and Sergei Vassilvitskii resolved this dilemma with $k$-means++. Instead of deterministically selecting the absolute farthest point (which falls into outlier traps) or picking uniformly at random (which clusters seeds together), $k$-means++ selects new seeds using a randomized distribution proportional to the squared shortest distance to existing centers ($D^2$-weighting).

The $k$-Means++ Seeding Algorithm
  1. Choose the first centroid $\mu_1^0$ uniformly at random from the dataset $\mathcal{X}$.
  2. For each remaining center $\ell = 2, 3, \dots, K$:
    • For every data point $x_i \in \mathcal{X}$, compute its squared Euclidean distance to the closest center already chosen: $$D(x_i)^2 = \min_{j \in \{1, \dots, \ell-1\}} \|x_i - \mu_j^0\|^2$$
    • Select the next center $\mu_\ell^0 = x_i$ with probability proportional to $D(x_i)^2$: $$\Pr(x_i \text{ is chosen}) = \frac{D(x_i)^2}{\sum_{r=1}^n D(x_r)^2}$$
  3. Proceed with standard Lloyd's alternating descent using $\mu_1^0, \dots, \mu_K^0$ as initial prototypes.

Why is $D^2$-sampling so effective? Consider what happens during the seeding process:

  • Points in a cluster that already contains a seed have $D(x_i) \approx 0$. Their selection probability drops to near zero, preventing redundant seeds in the same cluster.
  • Points in an unrepresented cluster located at distance $L$ from existing seeds contribute $D(x_i)^2 \approx L^2$. If that unrepresented cluster has $M$ points, the cluster as a whole contributes roughly $M \cdot L^2$ to the total sampling mass.
  • An isolated outlier point at distance $2L$ contributes $(2L)^2 = 4L^2$. But because it is only one point ($M = 1$), an unseeded cluster of 100 points at distance $L$ contributes $100 L^2$—twenty-five times more probability weight than the outlier!
Theorem: $\mathcal{O}(\log K)$ Approximation Guarantee of $k$-Means++

Let $F_{\text{opt}} = \min_{z, \mu} \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2$ be the globally optimal clustering distortion. The clustering returned by Lloyd's algorithm initialized with $k$-means++ seeding satisfies:

$$\mathbb{E}[F(z, \mu)] \le 8(\ln K + 2) \cdot F_{\text{opt}} = \mathcal{O}(\log K) \cdot F_{\text{opt}}$$

The expectation is taken over the randomness of the initial seeding choices. In expectation, $k$-means++ is mathematically guaranteed to be within an $\mathcal{O}(\log K)$ factor of the true global optimum.

In unsupervised learning, no one tells us the true number of clusters. Why does minimizing clustering distortion fail to choose $K$, and how do we mathematically penalize model complexity?

Model Selection: Penalized Distortion & Probabilistic Grounding

A natural first instinct is to optimize the number of clusters $K$ alongside the parameters by minimizing the distortion objective directly:

$$K^* = \arg\min_K F(K) = \arg\min_K \left[ \min_{z, \mu} \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2 \right]$$

This formulation fails completely: the distortion objective $F(K)$ is monotonically non-increasing in $K$. Every time we add an extra cluster centroid ($K \to K+1$), we give the model an additional degree of freedom to reduce Euclidean distances:

$$F(K+1) \le F(K)$$

If we set $K = n$, we can place a centroid directly on top of every single observation ($x_i = \mu_i$). The resulting distortion drops to $F(n) = 0$, but the model is completely useless—it has merely memorized the data rather than discovering structure.

To determine the optimal $K^*$, we must introduce a regularization penalty that penalizes model complexity:

$$K^* = \arg\min_K \left[ F(K) + \text{Penalty}(K) \right]$$

Probabilistic Grounding: Connection to Gaussian Mixture Models

Where do formal penalty functions come from? We can derive them directly by viewing $K$-means through the lens of Gaussian distributions.

Suppose data points are independently sampled from a mixture of $K$ spherical Gaussian distributions with identical variance $\sigma^2 I$ and uniform mixing weights $\pi_k = 1/K$:

$$p(x_i \mid z_i = k, \mu_k, \sigma^2) = \frac{1}{(2\pi \sigma^2)^{d/2}} \exp\left( -\frac{\|x_i - \mu_k\|^2}{2\sigma^2} \right)$$

Under hard assignment (where each point is assigned strictly to its most probable cluster), the joint log-likelihood of the dataset is:

$$\begin{aligned} \log p(X \mid z, \mu, \sigma^2) &= \sum_{i=1}^n \log\left[ \frac{1}{(2\pi \sigma^2)^{d/2}} \exp\left( -\frac{\|x_i - \mu_{z_i}\|^2}{2\sigma^2} \right) \right] \\[8pt] &= \sum_{i=1}^n \left( -\frac{d}{2}\ln(2\pi\sigma^2) - \frac{\|x_i - \mu_{z_i}\|^2}{2\sigma^2} \right) \\[8pt] &= -\frac{nd}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2} \underbrace{\sum_{i=1}^n \|x_i - \mu_{z_i}\|^2}_{F(K)} \end{aligned}$$

Maximizing the hard-assignment Gaussian log-likelihood is mathematically identical to minimizing the $K$-means distortion objective $F(K)$!

Each cluster center $\mu_k$ is a $d$-dimensional vector. Specifying $K$ centroids requires estimating $q = K \cdot d$ continuous parameters. This direct connection to maximum likelihood unlocks two classical information-theoretic model selection criteria:

  • Akaike Information Criterion (AIC):
    $$\text{AIC} = 2q - 2\log \hat{L} = 2Kd + \frac{1}{\sigma^2}F(K) + \text{const}$$
    Penalizes the number of parameters linearly with weight $2$.
  • Bayesian Information Criterion (BIC):
    $$\text{BIC} = q \ln(n) - 2\log \hat{L} = Kd \ln(n) + \frac{1}{\sigma^2}F(K) + \text{const}$$
    Imposes a heavier penalty scaled by $\ln(n)$, asymptotically identifying the true dimension of the underlying generative model.
  • The Geometric Elbow Method:

    In heuristic practice, one plots $F(K)$ against $K$ and looks for the "elbow"—the point where the rate of marginal reduction sharply diminishes:

    $$\Delta^2 F(K) = [F(K+1) - F(K)] - [F(K) - F(K-1)] = F(K+1) - 2F(K) + F(K-1)$$

    The elbow corresponds to the point of maximum positive discrete curvature $\Delta^2 F(K)$.

The Hidden Duality: Why Clustering and Dimensionality Reduction Are Two Sides of the Same Coin

With the clustering landscape clear, we can now address a natural question: Why are Dimensionality Reduction (such as PCA) and Clustering (such as $K$-Means) so frequently discussed together under the banner of "Unsupervised Learning"?

At first glance, they seem to solve completely different problems:

  • Dimensionality reduction finds a continuous low-dimensional subspace onto which high-dimensional features are compressed.
  • Clustering partitions data points into a discrete set of groups represented by centroid prototypes.

Yet beneath the surface, both paradigms are two realizations of the exact same mathematical engine: low-rank matrix factorization:

$$X \approx A B^T$$
  • Continuous Matrix Factorization (PCA): We approximate data matrix $X \in \mathbb{R}^{d \times n}$ as $X \approx W Z^T$, where the column vectors of $W \in \mathbb{R}^{d \times k}$ are continuous projection axes and the coordinates $Z \in \mathbb{R}^{n \times k}$ are continuous and orthonormal ($Z^T Z = I$).
  • Discrete Matrix Factorization ($K$-Means): We approximate data matrix $X \in \mathbb{R}^{d \times n}$ as $X \approx M Z^T$, where $M \in \mathbb{R}^{d \times K}$ holds continuous centroid coordinates, but $Z \in \{0, 1\}^{n \times K}$ is strictly constrained to be a discrete, binary one-hot assignment matrix ($z_{ik} \in \{0, 1\}$ with $\sum_k z_{ik} = 1$).

This matrix duality explains why $K$-means is computationally difficult while PCA is computationally tractable:

Because $Z$ is restricted to binary integers, $K$-means is a non-convex combinatorial optimization problem that is NP-hard. But notice what happens if we relax the discrete constraint: if we allow the rows of $Z$ to vary continuously as orthonormal vectors, the $K$-means objective function mathematically collapses directly into Principal Component Analysis!

Furthermore, both standard algorithms share the exact same geometric bottleneck: they are fundamentally linear tools. Linear PCA cannot unfold non-linear manifolds, and $K$-means cannot separate non-convex clusters (concentric circles, spirals). To escape this limitation, both paradigms deploy the exact same geometric philosophy:

  • In dimensionality reduction, we lift input coordinates into a high-dimensional feature Hilbert space where curves flatten into hyperplanes (Kernel PCA).
  • In clustering, we transform pairwise Euclidean distances into an affinity graph and compute the continuous eigenvectors of the Graph Laplacian (Spectral Clustering), which we will explore next.

Whether projecting continuously onto orthogonal subspaces or partitioning discretely into Voronoi cells, unsupervised learning is the unified pursuit of discovering latent structure without labels.
