The Big Picture: Structure Without Supervision

In supervised machine learning, an explicit target $y$ guides the algorithm toward a specific objective. But in the vast majority of real-world scenarios, labels do not exist. We are handed a raw, unlabeled dataset $\mathcal{X} = \{x_1, x_2, \dots, x_n\} \subset \mathbb{R}^d$ and asked to find meaningful underlying patterns.

How should we systematically think about Unsupervised Learning? In the Foundations of Machine Learning (FML) paradigm, the entire field splits cleanly along a single foundational dividing line: Do we make assumptions about how the data was generated?

The Unsupervised Learning Taxonomy
  • No Assumptions About Data Generation (Geometric & Matrix Projections):
    • Representation Learning (Continuous Subspaces): Rotating and projecting data onto optimal continuous low-dimensional subspaces $\implies$ PCA, Kernel PCA.
    • Clustering (Discrete Partitions): Grouping data into discrete geometric neighborhoods $\implies$ Lloyd's Algorithm ($K$-Means), Spectral Clustering.
  • Probabilistic Assumptions (Generative Modeling):
    • Estimation: Assuming data is drawn from a latent probability density (e.g., Gaussian Mixtures) and fitting parameters via maximum likelihood $\implies$ EM Algorithm, Density Estimation.

Notice the remarkable symmetry: PCA solves a continuous projection problem (finding the best low-rank subspace), while $K$-Means solves a discrete projection problem (finding the best partition of points into $K$ representative cluster centers).

The $K$-Means Formulation & Lloyd's Algorithm

Suppose we are given $n$ data points $x_1, x_2, \dots, x_n \in \mathbb{R}^d$. We want to partition them into $K$ distinct clusters $C_1, C_2, \dots, C_K$, each represented by a centroid vector $\mu_k \in \mathbb{R}^d$.

Let $z_i \in \{1, 2, \dots, K\}$ denote the cluster assignment index for point $x_i$. The quality of our clustering is measured by the total squared Euclidean distance from every point to its assigned centroid (often called the inertia or distortion objective):

$$F(z_1, \dots, z_n, \mu_1, \dots, \mu_K) = \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2 = \sum_{k=1}^K \sum_{i: z_i = k} \|x_i - \mu_k\|^2$$

This optimization problem is deceptively challenging: it couples discrete variables ($z_i$) with continuous variables ($\mu_k$). To solve it, Lloyd's Algorithm employs a coordinate descent strategy—alternating between two straightforward steps until convergence:

Lloyd's Alternating Algorithm
  1. Initialization: Pick initial centroids $\mu_1^0, \dots, \mu_K^0$ (or initial cluster assignments $z_1^0, \dots, z_n^0$).
  2. Mean Calculation Step (Centroid Update): With cluster assignments $z_i^{(t)}$ held fixed, compute the optimal centroid $\mu_k^{(t)}$ for each cluster $k$: $$\mu_k^{(t)} = \arg\min_{\mu} \sum_{i: z_i = k} \|x_i - \mu\|^2 = \frac{\sum_{i=1}^n x_i \mathbf{1}(z_i^{(t)} = k)}{\sum_{i=1}^n \mathbf{1}(z_i^{(t)} = k)}$$
  3. Reassignment Step (Cluster Update): With centroids $\mu_k^{(t)}$ held fixed, reassign each point $x_i$ to its closest centroid: $$z_i^{(t+1)} = \arg\min_{k \in \{1, \dots, K\}} \|x_i - \mu_k^{(t)}\|^2$$
  4. Repeat: Continue alternating between Mean Calculation and Reassignment until assignments no longer change.

The Nature of Clusters: Why Boundaries are Hyperplanes

What geometric shapes do $K$-means clusters take? Let us consider the simplest non-trivial case: $K = 2$ with two learned cluster means $\mu_1$ and $\mu_2$.

A data point $x$ is assigned to Cluster 1 if and only if it is at least as close to $\mu_1$ as it is to $\mu_2$:

$$\|x - \mu_1\|^2 \le \|x - \mu_2\|^2$$

Let us expand both Euclidean norms:

$$\|x\|^2 + \|\mu_1\|^2 - 2x^T \mu_1 \le \|x\|^2 + \|\mu_2\|^2 - 2x^T \mu_2$$

Notice that the quadratic term $\|x\|^2$ appears on both sides and cancels out completely! Rearranging the remaining terms yields:

$$2x^T \mu_2 - 2x^T \mu_1 \le \|\mu_2\|^2 - \|\mu_1\|^2$$
The Separating Hyperplane Equation
$$x^T (\mu_2 - \mu_1) \le \frac{\|\mu_2\|^2 - \|\mu_1\|^2}{2}$$

This is the equation of a half-space bounded by a flat hyperplane!

To see the geometry clearly, let us test what happens at the midpoint $m = \frac{\mu_1 + \mu_2}{2}$:

$$m^T (\mu_2 - \mu_1) = \left(\frac{\mu_1 + \mu_2}{2}\right)^T (\mu_2 - \mu_1) = \frac{\mu_2^T \mu_2 - \mu_1^T \mu_1}{2} = \frac{\|\mu_2\|^2 - \|\mu_1\|^2}{2}$$

The decision boundary is the perpendicular bisector of the line segment connecting $\mu_1$ and $\mu_2$. The normal vector pointing across the boundary is exactly the difference vector $\mu_2 - \mu_1$.

When generalized to $K > 2$ clusters, each cluster region is the intersection of $K-1$ half-spaces:

$$C_k = \left\{ x \in \mathbb{R}^d : x^T(\mu_j - \mu_k) \le \frac{\|\mu_j\|^2 - \|\mu_k\|^2}{2}, \quad \forall j \neq k \right\}$$

Because each half-space is convex, and the intersection of convex sets is always convex, $K$-means partitions space into convex polyhedral cells called a Voronoi Tessellation. This immediately reveals a core limitation: $K$-means cannot separate clusters that require non-linear or non-convex boundaries (such as concentric circles or intertwined spirals).

Why Lloyd's Algorithm Must Converge

A crucial question arises: Can Lloyd's algorithm get caught in an infinite loop, ping-ponging assignments back and forth forever?

The answer is an emphatic no. Lloyd's algorithm is mathematically guaranteed to terminate in a finite number of iterations. The proof rests on two pillars:

  1. Strict Monotonic Objective Reduction:

    In the reassignment step, each data point $x_i$ is reassigned to the centroid that minimizes $\|x_i - \mu_k^{(t)}\|^2$. Therefore:

    $$F(z^{(t+1)}, \mu^{(t)}) = \sum_{i=1}^n \|x_i - \mu_{z_i^{(t+1)}}^{(t)}\|^2 \le \sum_{i=1}^n \|x_i - \mu_{z_i^{(t)}}^{(t)}\|^2 = F(z^{(t)}, \mu^{(t)})$$

    If any point changes its cluster assignment, the objective value strictly decreases.

    Next, in the mean calculation step, $\mu_k^{(t+1)}$ is set to the exact sample mean of cluster $k$, which is the unique global minimizer of $\sum_{i: z_i=k} \|x_i - \mu\|^2$. Thus:

    $$F(z^{(t+1)}, \mu^{(t+1)}) \le F(z^{(t+1)}, \mu^{(t)})$$

    Hence, across every full iteration, the objective sequence strictly decreases whenever assignments change:

    $$F(z^{(t+1)}, \mu^{(t+1)}) < F(z^{(t)}, \mu^{(t)})$$
  2. Finite State Space of Partitions:

    There are $n$ data points and $K$ possible cluster labels. The total number of possible assignments $z = (z_1, \dots, z_n)$ is at most $K^n$, a finite number.

The Convergence Conclusion

Because the objective function strictly decreases whenever a reassignment occurs, no partition can ever be visited twice. Since the total number of partitions is finite, the algorithm must stop changing assignments after a finite number of steps $\implies$ Convergence is guaranteed.

The Critical Caveat: Convergence tells us that the algorithm will stop, but it says nothing about the quality of the converged solution. The $K$-means objective is non-convex with countless local minima. Lloyd's algorithm easily gets trapped in poor local configurations depending entirely on initialization.

Initialization Pitfalls & The Furthest-Point Failure

How should we choose the initial seeds? Two common heuristics are:

  • Random Partition: Assign each point randomly to one of $\{1, \dots, K\}$ and compute initial means. (This pulls all initial means close to the global dataset center due to the Law of Large Numbers, often performing poorly).
  • Random Centroids: Choose $K$ distinct points uniformly at random from the dataset $\mathcal{X}$. (Prone to picking multiple seeds from the same dense cluster, leaving other clusters unseeded).

One might wonder: Why not use a deterministic "furthest-point" heuristic? Pick $\mu_1$ as an arbitrary data point, and then greedily pick each subsequent center $\mu_\ell$ as the point that is farthest from all previously selected centers:

$$\mu_\ell = \arg\max_{x_i \in \mathcal{X}} \min_{j=1,\dots,\ell-1} \|x_i - \mu_j\|^2$$
The IITM FML Chocolate Challenge

Can you construct a dataset where this deterministic furthest-point initialization causes Lloyd's algorithm to converge to an arbitrarily bad approximation ratio compared to the optimal clustering?

The Counterexample: Consider data arranged on symmetric circular rings or elongated parallel pairs. By placing extreme outliers or choosing a symmetric layout, the greedy furthest-point rule deterministically selects outlier points or points on opposite ends of the same cluster boundary. The resulting Voronoi cells cut across natural clusters, trapping Lloyd's algorithm in an adversarial configuration with catastrophic approximation ratios.

$k$-Means++: The Power of $D^2$-Sampling

To resolve the trade-off between greedy determinism and naive uniform random selection, David Arthur and Sergei Vassilvitskii (2007) introduced $k$-means++.

Instead of deterministically picking the farthest point (which is fragile to outliers) or picking uniformly at random (which clusters seeds together), $k$-means++ picks new centers with a probability proportional to the squared distance to the nearest existing center.

The $k$-Means++ Seeding Algorithm
  1. Choose the first center $\mu_1^0$ uniformly at random from dataset $\mathcal{X}$.
  2. For $\ell = 2, \dots, K$:
    • For each $x_i \in \mathcal{X}$, compute its shortest distance to already chosen centers: $$D_i^2 = \min_{j \in \{1, \dots, \ell-1\}} \|x_i - \mu_j^0\|^2$$
    • Choose the next center $\mu_\ell^0 = x_i$ with probability: $$\Pr(x_i) = \frac{D_i^2}{\sum_{r=1}^n D_r^2}$$
  3. Run standard Lloyd's algorithm using $\mu_1^0, \dots, \mu_K^0$ as initial centers.

Why does this work so well? Points already near an existing center have $D_i \approx 0$ and have virtually zero chance of being picked again. Meanwhile, points far away in unrepresented clusters have high $D_i^2$ and dominate the sampling distribution.

Theoretical Approximation Guarantee
$$\mathbb{E}\left[ \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2 \right] \le 8(\ln K + 2) \min_{z_1, \dots, z_n} \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2 = \mathcal{O}(\log K) \cdot F_{\text{opt}}$$

The expectation is taken over the randomness in the algorithm's seeding choices. In expectation, $k$-means++ is guaranteed to be within an $\mathcal{O}(\log K)$ factor of the optimal clustering!

Model Selection: How to Choose $K$

A fundamental question in clustering is: How do we determine the true number of clusters $K$?

Attempting to find $K$ by simply minimizing the objective function $F(K)$ is mathematically futile:

$$F(K) = \min_{z, \mu} \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2$$

As $K$ increases, $F(K)$ is strictly monotonically decreasing. If we set $K = n$, we can place a centroid at every single data point, yielding a trivial and useless objective value of $F(n) = 0$.

To find the optimal $K^*$, we must introduce a regularization penalty that penalizes model complexity (larger $K$):

$$K^* = \arg\min_K \left[ F(K) + \text{Penalty}(K) \right]$$

Probabilistic Grounding: AIC and BIC

If we interpret $K$-means under a probabilistic framework (as a Gaussian Mixture Model with spherical covariance $\sigma^2 I$), the log-likelihood is directly proportional to the negative distortion objective: $\log \hat{L} \propto -F(K)$.

This allows us to leverage principled statistical criteria:

  • Akaike Information Criterion (AIC): $$\text{AIC} = 2q - 2\log \hat{L}$$ where $q = K \cdot d$ is the number of estimated parameters (the centroid coordinates).
  • Bayesian Information Criterion (BIC): $$\text{BIC} = q \log(n) - 2\log \hat{L}$$ which imposes a heavier penalty on sample size $n$, preferring simpler, more parsimonious models.
  • The Elbow Method: A geometric heuristic where one plots $F(K)$ against $K$ and identifies the "elbow"—the inflection point where adding more clusters yields diminishing marginal reduction in distortion.

Connecting the Dots: The Non-Linear Frontier

We have seen that standard $K$-means has two fundamental traits:

  1. It partitions space using linear Voronoi hyperplanes.
  2. It alternates over discrete assignment variables, which can be seen as an NP-hard combinatorial problem.
