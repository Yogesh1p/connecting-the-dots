Autoencoders: Foundations & The Information Leakage Problem

Before the rise of deep learning, one of the central problems in machine learning was representation learning: how can we describe high-dimensional data using a much smaller set of informative features?

Consider an image. Although it may contain hundreds of thousands of pixels, much of that information is redundant. Neighboring pixels often have similar values, edges occupy contiguous regions, and textures repeat. This means an image can often be represented using far fewer numbers than its raw pixel values suggest.

Long before neural networks, statisticians developed methods such as Singular Value Decomposition (SVD) and Principal Component Analysis (PCA) to exploit this redundancy. These methods compress data by projecting it onto a lower-dimensional space while preserving as much information as possible.

However, these techniques have an important limitation: they are fundamentally linear. They can only discover linear correlations in the data. If the underlying structure of the data is nonlinear—as is often the case for images, speech, and natural language—linear methods cannot represent it efficiently.

This naturally raises an important question:

Motivating Question

Can a neural network learn a nonlinear compressed representation of data, just as PCA learns a linear one?

Neural networks are universal function approximators capable of learning highly nonlinear transformations. More importantly, every hidden layer inside a neural network learns an internal representation of the input.

In supervised learning, these hidden representations are optimized to predict labels:

$$ \text{Image} \rightarrow \text{Representation} \rightarrow \text{Class Label} $$

The network learns whatever representation is most useful for classification.

But what if labels are unavailable?

Instead of learning representations that help predict a label, can we learn representations that preserve enough information to reconstruct the original input?

This simple idea led to one of the most influential architectures in representation learning: the Autoencoder.

Definition: Autoencoder

Definition

An autoencoder is a feedforward neural network trained to reconstruct its own input.

Internally, the network learns a code that represents the input. It consists of two components:

  1. An encoder that maps the input $x \in \mathbb{R}^n$ to a code $h \in \mathbb{R}^d$:
    $$ h=f_{\mathrm{enc}}(x) $$
  2. A decoder that reconstructs the input from the code:
    $$ \hat{x}=f_{\mathrm{dec}}(h) $$
$$ x \rightarrow h \rightarrow \hat{x} $$

Undercomplete Autoencoders

At first glance, the learning objective appears trivial. If the input and output are identical, why doesn't the network simply learn the identity function?

Indeed, if the encoder and decoder have enough capacity, that is exactly what happens. The network simply learns to copy the input to the output without discovering any useful structure in the data.

One of the simplest ways to prevent this trivial solution is to constrain the code dimension. If the code has fewer dimensions than the input,

$$ d < n, $$

the network can no longer copy every input independently. Instead, it must compress the data, preserving only the information necessary to reconstruct the original input.

The learned code therefore captures the most salient properties of the training data.

Training simply consists of minimizing a reconstruction loss between the input $x$ and its reconstruction $\hat{x}$.

For continuous data, Mean Squared Error (MSE) is commonly used:

$$ \mathcal{L}_{\mathrm{MSE}} = \frac12 \sum_{i=1}^{n} (x_i-\hat{x}_i)^2. $$

For binary data, Binary Cross Entropy (BCE) is typically used:

$$ \mathcal{L}_{\mathrm{BCE}} = - \sum_{i=1}^{n} \left[ x_i\log\hat{x}_i + (1-x_i)\log(1-\hat{x}_i) \right]. $$

When both the encoder and decoder are linear transformations, an undercomplete autoencoder learns the same subspace as Principal Component Analysis (PCA). With nonlinear activation functions, however, the encoder and decoder can learn nonlinear manifolds that PCA cannot represent. An undercomplete autoencoder may therefore be viewed as a nonlinear generalization of PCA.

Overcomplete Autoencoders

When the code dimension is equal to or larger than the input dimension,

$$ d ≥ n, $$

the network has enough capacity to simply memorize the identity function. Even a completely linear encoder and decoder can perfectly copy the input to the output without learning anything meaningful about the underlying data distribution.

Regularized Autoencoders

Rather than restricting the size of the code, another approach is to regularize the learning process itself. Regularized autoencoders allow large, expressive encoder and decoder networks while encouraging the learned code to possess desirable properties beyond simply copying the input.

  • Sparse Autoencoders encourage only a small subset of code units to activate for any input.
  • Denoising Autoencoders corrupt the input with noise and train the network to reconstruct the original clean input, forcing the model to learn the underlying structure of the data rather than memorizing individual inputs.
  • Contractive Autoencoders penalize the sensitivity of the learned code to small perturbations in the input, encouraging locally stable representations.

The Information Leakage Problem

Although autoencoders learn useful representations, they cannot be directly used as autoregressive generative models.

To see why, notice that every reconstructed output $\hat{x}_i$ is computed from the code $h$, and the code itself is computed from the entire input vector:

$$ \hat{x}_i = f_{\mathrm{dec}} \left( f_{\mathrm{enc}} (x_1,\ldots,x_i,\ldots,x_n) \right)_i. $$

Consequently, the prediction of $\hat{x}_i$ already has access to the true value $x_i$. Rather than learning the conditional distribution

$$ p(x_i \mid x_{<i}), $$

the network simply learns to copy $x_i$ through the code. This phenomenon is known as information leakage.

The reconstruction error may become extremely small, but the network has not learned how the data is generated. Instead, it has learned to exploit information that would not be available during generation.

When generating a new sample, the value of $x_i$ is unknown and must instead be sampled from

$$ x_i \sim p(x_i \mid x_{<i}). $$

Since a vanilla autoencoder was trained assuming that $x_i$ was already present in the input, it fails completely as an autoregressive generative model.

Bridging to MADE

The challenge is therefore to retain the efficiency of a feedforward neural network while eliminating information leakage.

Rather than allowing every output to depend on every input, we must enforce a causal structure so that the prediction of $\hat{x}_i$ depends only on the previous variables $x_{<i}$.

Remarkably, this can be achieved simply by masking selected connections in a standard feedforward network. The resulting architecture is called the Masked Autoencoder for Distribution Estimation (MADE), which combines parallel computation with the causal structure required for autoregressive modeling.
