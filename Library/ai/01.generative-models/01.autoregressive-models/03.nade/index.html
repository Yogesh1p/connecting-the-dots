NADE: Neural Autoregressive Distribution Estimators

A brief historical note: Neural Autoregressive Distribution Estimators (NADE) were invented long after Recurrent Neural Networks (RNNs). Chronologically, RNNs came first. But pedagogically, it is much cleaner to introduce NADE here. By keeping the sequence length fixed, NADE isolates a single, crucial upgrade—replacing linear equations with a shared hidden layer—without entangling it in the mechanics of time-steps and variable-length recurrence.

NADE strengthens autoregressive modeling by replacing the linear conditional predictor of FVSBN with a one-hidden-layer neural network. For each position $i$, a hidden representation is computed and then mapped to a conditional probability:

$$h_i = \sigma\!\left(A^i x_{\lt i} + c\right), \qquad \hat{x}_i = \sigma\!\left(\alpha^i h_i + b_i\right).$$

The hidden layer allows the model to capture nonlinear interactions among observed variables, something a purely linear predictor cannot do.

The parameter-scaling problem.

Assigning a separate weight matrix $A^i \in \mathbb{R}^{d \times (i-1)}$ to every conditional is costly. Summing over all positions gives

$$\sum_{i=1}^{n} d(i-1) = d\,\frac{n(n-1)}{2} = O(n^2 d)$$

parameters for the input-to-hidden mappings alone. Beyond the raw count, this design is statistically wasteful: the inputs to adjacent conditionals differ by only a single observation, yet each position learns entirely independent features. There is no mechanism for the model to transfer what it learns about earlier variables to later ones.

Weight sharing as the key idea.

NADE resolves this by tying the input-to-hidden weights across all positions. A single shared matrix

$$W \in \mathbb{R}^{d \times n}$$

replaces the family $\{A^i\}$, and the $i$-th conditional uses only the first $i-1$ columns:

$$h_i = \sigma\!\left(W_{:,\lt i}\,x_{\lt i} + c\right), \qquad \hat{x}_i = p(x_i = 1 \mid x_{\lt i}) = \sigma\!\left(\alpha^i h_i + b_i\right).$$

Because the same column $W_{:,j}$ appears in every conditional that conditions on $x_j$, the model is forced to learn features that are useful across the entire sequence, not just at a single position. The input-to-hidden parameter count drops to $dn = O(nd)$, and the shared structure enables an efficient left-to-right recurrence: the pre-activation at position $i+1$ is obtained by augmenting the pre-activation at position $i$ with a single rank-one update, rather than recomputing from scratch.

Definition: Neural Autoregressive Distribution Estimator (NADE)

NADE learns a single shared weight matrix $W \in \mathbb{R}^{d \times n}$ so that every conditional reuses the same input-to-hidden mapping:

$$h_i = \sigma\!\left(W_{:,\lt i}\,x_{\lt i} + c\right), \qquad \hat{x}_i = p(x_i = 1 \mid x_{\lt i}) = \sigma\!\left(\alpha^i h_i + b_i\right).$$

Columns of $W$ are shared across positions, so hidden pre-activations can be updated incrementally from left to right. Compared with unshared FVSBN-style networks, NADE reduces input-to-hidden parameter count from $O(n^2 d)$ to $O(nd)$ while retaining nonlinear expressiveness.

Extensions.

The NADE framework extends naturally beyond binary variables by modifying the output distribution while retaining the same autoregressive hidden representation.

Discrete variables

For non-binary discrete random variables $x_i \in \{1,\dots,K\}$ (e.g., pixel intensities ranging from $0$ to $255$), the output $\hat{x}_i$ parameterizes a categorical distribution rather than a Bernoulli. The hidden representation is computed as

$$h_i = \sigma(W_{\cdot,\lt i}x_{\lt i} + c),$$

and the conditional distribution is modeled as

$$p(x_i \mid x_{\lt i}) = \mathrm{Cat}(p_i^1,\dots,p_i^K),$$

where

$$\hat{x}_i = (p_i^1,\dots,p_i^K) = \mathrm{softmax}(A_i h_i + b_i).$$

The softmax function generalizes the sigmoid by transforming a vector of real-valued scores into a valid probability distribution over $K$ outcomes, ensuring non-negativity and unit normalization.

Intuition: Constructing the Softmax Function

Suppose our network outputs a vector of $K$ raw scores (logits), $z = A_i h_i + b_i$. These numbers can be anything—positive, negative, large, or small. We need to mechanically convert them into a valid probability distribution $p$. What mathematical rules must this conversion obey?

  1. Positivity: Probabilities cannot be negative. We solve this by taking the exponential of the scores: $e^{z_k}$. This forces every number to be strictly positive. Crucially, it also preserves the order: a higher raw score $z_k$ always produces a larger positive value $e^{z_k}$.
  2. Normalization: A valid probability distribution must sum to exactly $1$. We achieve this by dividing each positive value by the total sum of all $K$ positive values.

Combining these two simple requirements gives the softmax function for the $k$-th outcome:

$$ p_i^k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}} \quad \text{for } k=1,\dots,K $$

The softmax is simply the most direct mathematical tool to take arbitrary real numbers, make them positive, and scale them to sum to one. It naturally generalizes the sigmoid function from 2 choices to $K$ choices.

Continuous variables (RNADE)

For real-valued variables $x_i \in \mathbb{R}$ (e.g., speech signals), each conditional can be modeled using a continuous distribution. A common choice is a mixture of Gaussians, giving rise to the Real-valued NADE (RNADE). In this case, the conditional distribution takes the form

$$p(x_i \mid x_{\lt i}) = \sum_{j=1}^{K} \pi_i^j \, \mathcal{N}\!\left(x_i;\mu_i^j,\sigma_i^j\right),$$

where $\pi_i^j$ are mixture weights and $(\mu_i^j,\sigma_i^j)$ are the mean and standard deviation of the $j$-th Gaussian component. These parameters are predicted from the hidden state:

$$h_i = \sigma(W_{\cdot,\lt i}x_{\lt i} + c), \qquad \hat{x}_i = (\pi_i^1,\dots,\pi_i^K, \mu_i^1,\dots,\mu_i^K, \sigma_i^1,\dots,\sigma_i^K) = f(h_i).$$

In practice, the standard deviations are typically parameterized using an exponential transform to ensure $\sigma_i^j \gt 0$. This extension allows NADE to model complex continuous densities while preserving the autoregressive factorization and efficient shared-parameter structure.

Remark: Hidden Units as Deterministic Features

Although $h_i$ is commonly called a hidden layer, it is more precise to regard it as a deterministic feature vector derived from the observations. Given $x_{\lt i}$, the value of $h_i$ is fixed:

$$h_i = \sigma\!\left(W_{:,\lt i}\,x_{\lt i} + c\right).$$

NADE therefore contains no latent random variables. The $h_i$ serve purely as nonlinear summaries of the observed context, used to parameterize each conditional distribution.
