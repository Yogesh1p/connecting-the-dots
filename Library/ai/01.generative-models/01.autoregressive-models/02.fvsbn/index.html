In our introduction to autoregressive models, we established that instead of storing $p(x_i \mid x_1, \dots, x_{i-1})$ as an impossibly large lookup table, we could compute it using a learned function $f_\theta$. But we never specified what $f_{\theta_i}$ actually looks like.

This article builds up the answer, starting from the simplest possible parameterization and progressively replacing its weaknesses with better ideas. We begin by exploring Fully Visible Sigmoid Belief Networks (FVSBN). Throughout this section, we use MNIST as our running example: $28 \times 28 = 784$ binary pixels in raster scan order, $x_1, \dots, x_{784} \in \{0,1\}$.

FVSBN

A common and conceptually simple choice is to model each conditional distribution using logistic regression. In this setting, the conditional probability is parameterized as

$$p_\theta(x_i = 1 \mid x_{\lt i}) = \sigma\!\left( W_i^\top x_{\lt i} + b_i \right),$$

where $W_i$ and $x_{\lt i}$ are vectors, allowing the summation to be expressed cleanly as a dot product.

where $\sigma(\cdot)$ denotes the logistic sigmoid function. So each variable is predicted using a sigmoid applied to a linear function of the previous variables. The name Fully Visible Sigmoid Belief Network (FVSBN) reflects three properties: the model defines probability directly over the observed variables (fully visible), each conditional distribution is parameterized with a sigmoid (logistic regression), and the joint distribution is factorized as a directed probabilistic model --- historically called a belief network.

To see why this parametric shift is essential, count the numbers. Suppose a conditional distribution depends on $m$ previous binary variables: $p(x_i \mid x_1, \dots, x_m)$.

If we use a lookup table, we must assign a probability to every possible combination. With 2 states per variable, that is $2^m$ unique configurations. The table requires $2^m - 1$ independent parameters. If $m=20$, that is over a million numbers to learn for a single conditional distribution.

Now look at the logistic regression alternative used in FVSBN. Instead of memorizing every state, we compute a raw score $z$ using a linear combination of the inputs:

This is the same idea as the earlier $W_i^\top x_{\lt i} + b_i$ notation. For this one conditional, the weight vector $W_i$ can be written by listing its individual entries:

$$ W_i = \begin{bmatrix} \alpha^i_1 \\ \alpha^i_2 \\ \vdots \\ \alpha^i_m \end{bmatrix}, \qquad x_{\lt i} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_m \end{bmatrix}, \qquad b_i = \alpha^i_0. $$

So the symbol changes from $W$ to $\alpha$ only because we are opening up the vector and naming each per-input weight explicitly while we count parameters.

$$ z = \alpha^i_0 + \alpha^i_1 x_1 + \alpha^i_2 x_2 + \dots + \alpha^i_m x_m $$

Count the parameters in that line. There is one weight $\alpha^i_j$ for each of the $m$ inputs. There is one bias term $\alpha^i_0$. That is exactly $m + 1$ parameters.

That linear combination gives a raw score $z$, which could be any real number. But a valid probability must live between 0 and 1. To map $z$ into that range, we pass it through the logistic sigmoid function:

$$ \sigma(z) = \frac{1}{1 + e^{-z}} $$

Look at the right side of that equation. It contains the score $z$ and constants. It introduces no new weights or parameters to learn. The mapping is purely mechanical, meaning the total parameter count for the conditional distribution remains strictly $m+1$.

By making the structural assumption that past variables influence the current one additively, the complexity drops from exponential ($O(2^m)$) to linear ($O(m)$).

Definition: Fully Visible Sigmoid Belief Network (FVSBN)

A Fully Visible Sigmoid Belief Network parameterizes each conditional as:

$$\hat{x}_i = p(x_i = 1 \mid x_{\lt i};\, \alpha^i) = \sigma\!\left(\alpha^i_0 + \sum_{j=1}^{i-1} \alpha^i_j\, x_j\right)$$

where $\sigma(z) = 1/(1+e^{-z})$ and $\alpha^i$ are learned parameters for position $i$. The joint:

$$p(x_1, \dots, x_n) = \prod_{i=1}^{n} p(x_i \mid x_{\lt i})$$

Parameters: $1 + 2 + \cdots + n = O(n^2/2)$.

Example: Evaluating and Sampling from FVSBN

Define the conditional probabilities using the parameter matrix

$$\hat{x}_i = p(x_i = 1 \mid x_{\lt i};\, \alpha^i) = \sigma\!\left(\alpha^i_0 + \sum_{j=1}^{i-1} \alpha^i_j\, x_j\right).$$

Collect the parameters into a lower--triangular matrix

$$A = \begin{bmatrix} \alpha^1_0 & 0 & 0 & 0 \\ \alpha^2_0 & \alpha^2_1 & 0 & 0 \\ \alpha^3_0 & \alpha^3_1 & \alpha^3_2 & 0 \\ \alpha^4_0 & \alpha^4_1 & \alpha^4_2 & \alpha^4_3 \end{bmatrix}, \qquad \tilde{x} = \begin{bmatrix} 1 \\ x_1 \\ x_2 \\ x_3 \end{bmatrix}.$$

Then the vector of conditional probabilities can be written compactly as

$$\hat{\mathbf{x}} = \sigma(A \tilde{x}),$$

where the sigmoid function is applied element-wise.

To evaluate $p(X_1=0,\, X_2=1,\, X_3=1,\, X_4=0)$:

  1. Compute all $\hat{x}_i$ using the matrix form above.
  2. Multiply: $(1-\hat{x}_1) \times \hat{x}_2 \times \hat{x}_3 \times (1-\hat{x}_4)$

To sample:

  1. Sample $x_1 \sim \text{Bernoulli}(\hat{x}_1)$
  2. Sample $x_2 \sim \text{Bernoulli}(\hat{x}_2(x_1))$, and so on

The Asymmetry of autoregressive models:

Autoregressive models separate evaluation and generation in an important way. Given a known datapoint, the likelihood $p(x)$ can often be computed efficiently, since the conditional terms $p(x_i \mid x_{\lt i})$ are evaluated with inputs that are already known. In contrast, sampling is inherently sequential: each variable must be generated before later conditionals can be evaluated. This difference between efficient likelihood evaluation and sequential generation is a defining property of autoregressive modeling.

Let the conditional distribution be parameterized by a function

$$f_{\theta_i}(x_{\lt i}) = \sigma\!\left(\alpha^i_0 + \sum_{j=1}^{i-1} \alpha^i_j\, x_j\right),$$

which is simply a logistic regression model for variable $x_i$.

Then each conditional can be written compactly as

$$p(x_i = 1 \mid x_{\lt i}) = f_{\theta_i}(x_{\lt i}).$$

Using the autoregressive factorization, the joint distribution becomes

$$p(x_1,\dots,x_n) = \prod_{i=1}^{n} p(x_i \mid x_{\lt i}) = \prod_{i=1}^{n} f_{\theta_i}(x_{\lt i}).$$

FVSBN is valid but limited, since the function $f_\theta$ is a logistic regression and therefore models only linear dependencies. To obtain richer, more expressive conditionals, we next replace $f_\theta$ with neural networks.
